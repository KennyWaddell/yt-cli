DESCRIPCIÓN
-----------
YT-CLI para Windows es una interfaz gráfica moderna, nativa y ultraligera
diseñada para buscar, reproducir y descargar contenido de YouTube, TikTok,
Twitter/X y más de 1000 plataformas con aceleración por hardware (GPU).

REQUISITOS
----------
1. Windows 7 SP1, 8.1, 10 o 11 (32-bit o 64-bit).
2. Python 3.8 o superior instalado (marcar casilla "Add python to PATH").
3. Binarios multimedia en la carpeta 'bin/' o instalados en el sistema:
   - yt-dlp.exe
   - mpv.exe
   - ffmpeg.exe

INSTRUCCIONES DE USO RÁPIDO
---------------------------
1. Ejecuta 'descargar_binarios.bat' para obtener 'yt-dlp.exe' de forma automática.
2. Coloca 'mpv.exe' y 'ffmpeg.exe' dentro de la subcarpeta 'bin/'.
3. Haz doble clic en 'YT-CLI.bat' para iniciar la aplicación.

CARACTERÍSTICAS
---------------
* Streaming fluido con decodificación acelerada por hardware (D3D11 / DXVA2).
* Descargas MP4 (360p, 480p, 720p, 1080p, 30/60 FPS) y MP3 (320k, 192k, 128k).
* Historial local con reanudación automática donde lo dejaste.
* Soporte para cookies de sesión de Brave, Chrome, Firefox y Edge.
* Modos visuales Tema Oscuro y Tema Claro.
* Cero consumo excesivo de memoria RAM (~22 MB).
